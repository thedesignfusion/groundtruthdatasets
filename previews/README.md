# previews/

False-color **RGB previews** of each hyperspectral cube — the JPEGs the
dashboard cards and detail pane show. One file per scene, named
`<stem>_rgb.jpg`.

## What lives here

`<stem>_rgb.jpg` — 3-band false-color composite of the hyperspectral
cube. Generated by picking three well-spaced bands (typically near-IR /
red / green) and normalizing per-channel to 0-255.

All go through Git LFS (see `.gitattributes`) — a few hundred KB each
adds up when you have 655 scenes.

## How to regenerate one

```python
from detector import load_cube, false_color_rgb
cube = load_cube('path/to/scene.mat')
rgb  = false_color_rgb(cube)                     # returns HxWx3 uint8
import PIL.Image; PIL.Image.fromarray(rgb).save('previews/<stem>_rgb.jpg')
```

Or run `notebook_dataset_audit_colab.ipynb` — it regenerates the whole
preview set from the Drive cubes.

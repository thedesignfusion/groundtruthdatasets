# Ground Truth Datasets

Public dashboard for **hyperspectral anomaly-detection ground truth**.
Browse 655 scenes across 8 sensor families, filter by anomaly category,
open the source paper for each dataset, and download the raw cubes and
labeled overlays from Google Drive.

Live at **https://groundtruthdatasets.vercel.app**.

Maintained by [Allotrope 21 Labs](https://allotrope21labs.org) ·
built with [The Design Fusion](https://thedesignfusion.co).

`.jpg` RGB preview, and (where available) a ground-truth mask.

## Labeled overlays

Every scene shows two views in the detail pane:

- **Raw preview** — the false-color RGB composite from the cube.
- **Labeled overlay** — candidate anomalies highlighted in the scene's
  category color (aircraft = orange, urban = cyan, vegetation = lime,
  etc.). The default view is Labeled.

The shipped overlays are generated by an **RGB-space Mahalanobis proxy**
(`tools/generate_overlays.py`) — a fast triage layer that shows where the
scene's outliers sit. For **paper-authoritative labels**, run
[`notebook_labeled_overlays_colab.ipynb`](notebook_labeled_overlays_colab.ipynb)
in Google Colab: it mounts your Drive, pairs every `_gt.mat` mask with
its cube and preview, colorizes each class with a distinct color, bakes a
class legend into every JPEG, and rebuilds the payload. Drop the new
payload back in, re-bake, push — the dashboard then shows definitive
paper-GT labels instead of the RX proxy.

## Regenerating the dashboard

The dashboard is a single self-contained HTML file: metadata, thumbnails,
labeled overlays, and Drive links are all baked in.

```bash
# 1. Audit the Drive folder (in Colab) and download dataset_full_payload.json.
#    See notebook_dataset_audit_colab.ipynb in the roofflowfin repo.

# 2. Add category classification + normalized Drive URLs.
python tools/augment_payload.py

# 3. Generate labeled overlays.
#    - Fast RGB proxy (this repo):  python tools/generate_overlays.py
#    - Definitive paper GT (Colab): notebook_labeled_overlays_colab.ipynb

# 4. Bake the payload into index.html.
python tools/bake.py

# 5. Commit + push. Vercel redeploys automatically.
git add index.html && git commit -m 'Refresh dashboard' && git push
```

## Hosting

Static HTML on Vercel. `vercel.json` sets clean URLs. No build step.
Any HTTP host (GitHub Pages, Netlify, Cloudflare Pages, S3+CloudFront)
would work equally well — just drop `index.html` at the root.
